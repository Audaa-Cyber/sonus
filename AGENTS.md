# Sonus agent guidance

## Design direction
Sonus is a premium crypto payment-intelligence platform, not a generic crypto wallet or AI chatbot. The visual language is cinematic, restrained, and editorial: midnight black, warm sand, porcelain, and a selective signal-blue accent. Use generous negative space and concise copy.

## Before adding UI
Read `.agents/skills/21st-cli-use/SKILL.md`. When the 21st CLI is authenticated, search the 21st.dev catalog before creating a new reusable component. Inspect the actual code and adapt it to Sonus tokens. If the CLI is not available in the environment, state that limitation and continue only with clearly original components.

## Visual constraints
- Keep the sand landscape, bird murmuration, particle orb, feather motif, and continuous signal thread as a connected visual story.
- Avoid clutter, generic gradients, excessive cards, purple AI styling, and gratuitous glow.
- The orb currently represents the voice interface visually; do not claim it captures or understands real speech.
- Respect `prefers-reduced-motion`, responsive layouts, semantic HTML, and keyboard focus.
- Keep payment examples explicitly illustrative and never imply that a real payment was sent.
- The original Sonus font files were not present in the fresh repository. Typography is currently assigned three roles (display, body, metadata) using provisional web fonts; replace them only when the approved font files are available.
